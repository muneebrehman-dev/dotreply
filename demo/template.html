Part 1

How I read DotReply

An AI sales agent that turns abandoned Shopify checkouts into iMessage conversations. It answers what's holding the shopper back and walks them back to checkout. You earn only on revenue you recover.

~$35k / mo

What one extra point of recovery rate is worth on a $5M/month brand, using your own calculator's assumptions.

0 links

Allowed before the shopper replies (Sendblue's pre-reply rules and your own terms). The first message can't sell.

50 / day

New contacts per line on Sendblue's standard plans. Volume is capped, so who you text matters.

Sent→Seen→Reply→Blocker solved→Checkout link→Purchase

Reply rate is the gate. Every later stage only exists if the first message earns an answer.

Part 2

Three upgrades I'd make first

OPENER TODAY · FROM DOTREPLY.AI

Hey Alex! Still thinking about the Everyday Tee? Happy to help if you have a question.

Reads like an automated reminder and gives the shopper nothing to answer.

OPENER BUILT TO EARN A REPLY

{v2_opener}

Brand, exact item, one two-second question. The answer also tells the agent why they stopped.

Earn the reply

A specific, low-effort opener that doubles as a diagnosis. A/B test openers on reply rate and block rate, per brand.

Diagnose, solve, then close

Find the blocker (fit, shipping, timing, trust, price), answer with store facts only, send the link once it's solved. Discounts last, within brand limits, never stacked on an email code.

Prove it's incremental

Hold out about 10% of reachable checkouts and report extra revenue against that group, so 8-figure brands trust the number you bill on.

  • Guardrails built in: any stop signal ends the thread, honest if asked "is this a bot?", no invented stock, codes or delivery dates, order issues go to the team.
  • Who to text: with capped lines, prioritise high-value carts, returning customers and shoppers email didn't win back.

In production I'd run the same harness on your Claude setup and grow the test set from real transcripts.

Part 4

How I'd start

Week 1 · Learn from real chats

Tag every lost conversation by blocker and stage. Turn each failure into a test case, so the test set reflects your real shoppers. Set up stage metrics: reply rate, block and opt-out rate, link clicks, revenue per message sent.

Week 2 · Ship and measure

Launch the improved agent on one brand as an A/B test with a holdout group. Review daily. Every prompt change has to pass the full test set before it goes live.
